## Casos de Uso:

* Test Ivan: Enfocado en ventas grandes. Filtra los pedidos que superan 
un monto específico ($12.000) dando el cálculo matemático al motor SQL 
mediante HQL. Cruza información de 5 tablas distintas y utiliza polimorfismo 
para detallar el tipo exacto de unidad de venta involucrada. Finaliza calculando 
la ganancia neta real de cada ticket al contrastar la venta contra el costo de 
producción.

* Test Cande: Ranking de unidades: busca un festival, calcula cuánto recaudó cada 
unidad de venta con sus pedidos y las ordena de mayor a menor recaudación.

* Test Nico: Informe económico: busca un festival y muestra un resumen completo de ventas 
y costos: pedidos, platos vendidos, recaudación, costos, unidades participantes y 
ganancia estimada.

* Test Lucas: Prueba y consultar la información del sistema. Obtiene los platos, pedidos 
y detalles de pedidos desde la base de datos mediante las clases ABM, y genera un 
informe con diferentes estadísticas. Ademas permite consultar precios, costos, ganancias 
y márgenes de los platos, además de conocer la cantidad de pedidos, los platos más vendidos, 
los ingresos generados por cada plato y los ingresos totales.
